# 新チャンネル 第1話 下書き
## 「AIだけでYouTubeチャンネルを作ってみた。費用と再生数を全部公開」

- 長さ：約8分（16:9）＋ Shorts 2本
- 映像：Claude Codeとのやりとりの画面録画、What If Labの完成動画の抜粋、費用の表のアニメ
- チャンネル名：**AIでつくる、27歳の記録**（決定）
- 声：VOICEVOX。What If Labと区別するため、玄野武宏（B案）を推奨。サンプルは `voice_samples/`。あなたのひとことは字幕（吹き出し）で入れる
- 【あなた】と書いた部分は、あなたの本当の感想や数字を入れる場所です（ここが一番大事）
- 【要確認】は、公開前に正しい数字に差し替える部分です

### タイトル案（参考チャンネルの分析を反映）
型：**［あなたの立場］＋［AIに任せたこと］＋［具体的な数字・期間］＋［結果］**
1. **プログラミング経験ゼロの27歳会社員が、AIだけでYouTubeを始めた結果｜1本61円、再生数は「1」**（推奨）
2. AIに動画を全部作らせて30日。費用と再生数を全部公開します
3. 1本61円でAIに動画を作らせたら、再生数は12時間で「1」でした

### 参考にしたチャンネルから学ぶこと（Masayume AI Lab、動画1本・6日で16万回再生）
真似しないこと：タイトルの言い回し、サムネイルのデザイン、ロゴ
取り入れること（型だけ）：
- 主人公の「立場」をタイトルの先頭に置く（例：「コードが書けない40歳」）→ 視聴者が自分を重ねられる
- 具体的な数字と期間を入れる（金額、日数）
- 結果が気になる終わり方にする
- サムネイルは「感情が分かる顔」＋「大きな数字」。顔出ししない場合は、手元の写真か、VOICEVOXキャラクターの立ち絵（利用規約を確認してから）で代わりにする。実在しない人物の顔をAIで作って本人のように見せることはしない

- 2行目（特大・赤）：再生数「1」
- 3行目：AIだけで作った結果…
- 背景：What If Labの動画の画面と、Claude Codeの画面。手元（キーボードとスマホのYouTube Studio）の写真があれば右側に置く
