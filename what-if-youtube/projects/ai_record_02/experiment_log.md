# 実験ログ — AIだけでアプリを作ってみた（動画制作の管理アプリ）

この記録がそのまま動画の素材になる。盛らない・消さない・後から書き換えない。

## ルール
1. あなたの指示は、送った文章をそのまま記録する（言い直さない）
2. AIがやったこと、かかった時間、うまくいかなかったことを毎回書く
3. アプリの画面は、毎回ブラウザで自動録画する（Playwright）。これが動画の画面収録の代わりになる
4. 追加の費用：0円で進める（Claude Code Proの範囲内）。お金がかかる場面が来たら、その前に止めて確認する
5. 終了条件：あなたが「実際に1週間使えた」と言えるか、「ここで諦める」と決めたとき
