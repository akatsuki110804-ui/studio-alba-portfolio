# YouTube API の準備（2026-10-13 夜にやる）

パソコンで行う。所要 30分〜1時間の見込み。**パスワード・キー・トークンは絶対にチャットに貼らない。**

## 先に知っておくこと（重要）
- 新しく作ったAPIプロジェクトからアップロードした動画は、Googleの**監査（審査）に通るまで「非公開」から変えられない**と、複数の資料に書かれている（2020年7月28日以降に作られたプロジェクトが対象）。公式ページでも確認する。
- つまり今夜の準備だけでは、**自動アップロード → 公開** はまだできない。監査の申請をして、通るまでは数日以上かかる見込み。
- 一方で、**自分のチャンネルの数字を読む（アナリティクス）** には監査はいらない見込み。今夜の準備で、再生数や「視聴を継続」を自動で台帳に入れられるようになる可能性がある。
- アップロード1回にかかる「割り当て（クォータ）」の量は資料によって 100 と 1,600 で食い違っている。Cloud Console の画面で確認する。

## 手順
1. https://console.cloud.google.com/ に、**チャンネルを持っているGoogleアカウント**でログイン
2. 上のプロジェクト選択 →「新しいプロジェクト」→ 名前 `ai27-youtube` → 作成
3. 「APIとサービス」→「ライブラリ」で次の2つを検索して「有効にする」
   - YouTube Data API v3
   - YouTube Analytics API
4. 「APIとサービス」→「OAuth同意画面」
   - ユーザーの種類：外部
   - アプリ名：`ai27-youtube`、サポートメール：自分
   - テストユーザー：**自分のGoogleアカウント**を追加
   - 公開ステータスは「テスト」のままでよい
5. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
   - アプリケーションの種類：**デスクトップアプリ**
   - 作成後、JSONをダウンロード（`client_secret_….json`）。**チャットには貼らない**
6. ここまでできたら、チャットで「5まで終わった」と教える
   - 次の手順（ログインして許可 → 発行された鍵を、この作業環境の「環境の設定」に安全に登録する）を案内する
   - 登録先：作業画面の上部の環境メニュー →「編集」→ ネットワークのシークレット（または環境変数）。新しいセッションから使える
7. 監査の申請（任意・後日でも可）
   - YouTube API サービスの監査・クォータ申請フォームから申請する。内容は一緒に下書きする

## 終わったあとにできること
| できること | 監査なしで | 監査に通ったら |
|---|---|---|
| 再生数・視聴者維持率などを自動で取得して台帳に入れる | できる見込み | できる |
| 動画を非公開でアップロード | できる（ただし非公開から変えられない可能性） | できる |
| 長尺を非公開でアップロード → OK後に公開 | ✗ | できる |
| 承認済み長尺のShortsを予約公開 | ✗ | できる |
