## B. 一般に注意が必要な領域（確認項目）

以下は「該当する可能性があれば R15 が指摘し、ユーザーが判断する」ための確認項目の列挙です。法律やポリシーの解釈・適否の判断はここには書きません。該当しそうな場合は、最新の公式情報で確認するか、必要に応じて専門家に相談します。

| # | 領域 | 確認すること |
|---|---|---|
| B1 | YouTubeのコミュニティガイドライン・各種ポリシー | 内容がポリシーの対象領域（危険な行為、誤情報、ハラスメント 等）に触れていないか |
| B2 | 改変・合成コンテンツの開示 | AIで作った・加工した部分があるのに、開示設定や説明が抜けていないか（既存ルール: 「はい」にする） |
| B3 | 景品表示法に関わる可能性のある領域 | 実際より著しく良く見せる表現、根拠の示せない「No.1」「最安」等、プレゼント・特典の表現がないか |
| B4 | 医薬品医療機器等法（薬機法）に関わる可能性のある領域 | 健康・美容・身体への効果効能をうたう表現がないか |
| B5 | ステルスマーケティング（広告であることの表示） | 提供・案件・アフィリエイトがあるのに、その表示がないか |
| B6 | 著作権・肖像権・商標 | 他者の作品・映像・音楽・キャラクター・ロゴ・実在の人物の顔や声を、許可なく使っていないか |
| B7 | 名誉・信用 | 実在の人物・企業・サービスを根拠なく悪く言っていないか |
| B8 | 個人情報・プライバシー | 画面録画などに個人情報・通知・他人の情報が映っていないか |
| B9 | 金融・投資・お金の話 | 利益を約束・保証するような表現がないか |
| B10 | 子ども向け設定 | 子ども向けと受け取られる作りになっていないか（設定は「子ども向けではない」） |
