# R08 構成設計

- 工程: 企画
- 上流: R07 テーマ選定、R05 視聴者分析
- 下流: R09 フック作成、R10 台本作成、R11 タイトル作成、R12 CTA設計、R18 図解作成
- ユーザー承認: 不要（台本承認（G2）で台本と合わせて確認するため）
- 既存の実装: what-if-youtube/src/planning.py（storyboard工程）（絵コンテ（カット・素材種別・モーション指定）を作る）
- 状態: 下書き（ユーザー回答待ち）

## 目的
採用された企画を、尺の中で「どの順で何を見せ・言うか」のシーン（カット）構成に落とし込む。長尺と派生Shortsの切り出し位置も決める。

## 責任範囲
### やること
- シーン分割と秒数の割り当て
- 各シーンの役割（フック・本題・根拠・まとめ・CTA）の決定
- 画面に映すもの（画面録画・AI動画・モーショングラフィック・テキスト）の指定
- 派生Shortsに使う区間の指定

### やらないこと
- セリフの執筆（→R10）
- フック文言の作成（→R09）
- 企画内容の変更（変更が必要ならR07へ）

## 入力情報
- videos/<YYYYMMDD>_<slug>/02_plan/theme_decision.md
- rules/tone_and_structure.md（参考構成：【未確定：ユーザー回答待ち】）
- videos/<YYYYMMDD>_<slug>/01_research/audience.md
- ブリーフの尺（【未確定：ユーザー回答待ち】）

## 作業手順
1. ブリーフの形式・尺と、rules/tone_and_structure.md の参考構成を確認する
2. シーンを分け、各シーンに秒数を割り当てる（合計が尺に収まること）
3. 各シーンの役割・伝える要点・画面の中身・素材種別を書く
4. 図解が必要なシーンには、示すデータとその出典候補を書く
5. 派生Shortsの区間と、Shorts用に足す冒頭1秒のフック位置を書く
6. structure.md に保存する

## 出力形式
ファイル: videos/<YYYYMMDD>_<slug>/02_plan/structure.md

| シーン | 開始秒 | 終了秒 | 役割 | 伝える要点 | 画面の中身 | 素材種別(録画/AI動画/図解/文字のみ) | Shorts使用 |
|---|---|---|---|---|---|---|---|
| S1 | 0 | 〇 | フック | | | | Shorts1 |

末尾に: 合計秒数 / 派生Shorts一覧（区間・単体で意味が通るか） / 参考構成との違いとその理由

## 完了条件
- [ ] 合計秒数がブリーフの尺以内
- [ ] 全シーンに役割と素材種別がある
- [ ] 図解シーンに出典候補がある
- [ ] 派生Shortsが単体で意味が通る区間になっている
