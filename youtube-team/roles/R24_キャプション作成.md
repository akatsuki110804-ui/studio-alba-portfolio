# R24 キャプション作成

- 工程: 投稿
- 上流: R13 台本レビュー、R11 タイトル作成、R12 CTA設計、R14 事実確認、R15 表現チェック、R16 素材収集、R21 音声調整
- 下流: R23 投稿管理
- ユーザー承認: 不要（公開前承認（G4）でアップロード設定と一緒に確認するため）
- 既存の実装: what-if-youtube/docs/shorts_v2_upload_kit.md（説明文・固定コメントの手書き例）（自動生成は未実装）
- 状態: 下書き（ユーザー回答待ち）

## 目的
YouTubeでの「キャプション」にあたる文字情報（説明文＝概要欄、固定コメント、ハッシュタグ、タグ、出典一覧、クレジット表記）を作る。

## 責任範囲
### やること
- 説明文（概要欄）の執筆
- R12のCTAの組み込み（文言は変えない）
- ハッシュタグ・タグ案の作成
- 出典一覧とクレジット表記（例: VOICEVOX、AI生成の明記）の記載
- 固定コメント文の作成

### やらないこと
- アップロード・公開設定（→R23）
- 動画タイトル（→R11）
- CTA文言の変更（→R12）
- 確認されていない事実の追加
- 字幕ファイルの作成（YouTubeの字幕機能の意味の「キャプション」は→R19）

## 入力情報
- videos/<YYYYMMDD>_<slug>/03_script/script_approved.md
- videos/<YYYYMMDD>_<slug>/03_script/cta.md
- videos/<YYYYMMDD>_<slug>/03_script/title.md
- videos/<YYYYMMDD>_<slug>/04_review/fact_check.md
- videos/<YYYYMMDD>_<slug>/04_review/expression_check.md
- クレジット表記（R16・R21）
- ハッシュタグ・タグ方針（【未確定：ユーザー回答待ち】）

## 作業手順
1. 承認済み台本の要点を3行以内でまとめる
2. 説明文の冒頭を書く（タイトル・フックと同じ文にしない）
3. 本文を書き、事実主張は fact_check.md で「確認済み」のものだけ使い、出典を併記する
4. R12の説明文用CTA・固定コメント用CTAをそのまま入れる
5. クレジット表記・ハッシュタグ・タグを入れる
6. 新たな表現がある場合はR15に点検を依頼し、description.md に保存する

## 出力形式
ファイル: videos/<YYYYMMDD>_<slug>/08_publish/description.md（対象ごと）

```markdown
# 説明文（作成: R24／対象: 長尺 or Shorts#）
## 説明文
<冒頭>
<本文（出典つき）>
<CTA（cta.mdより）>
<クレジット: VOICEVOX:話者名／映像の一部はAI生成 など>
<ハッシュタグ>
## 固定コメント
## タグ
## チェック
- 使用した主張ID:
- R15点検: 済/不要（台本と同一表現のみ）
```

## 完了条件
- [ ] 事実主張がすべて確認済みのIDに紐付き、出典がある
- [ ] CTAがcta.mdと一致
- [ ] クレジット表記が漏れていない
- [ ] 新しい表現はR15点検済み

## 次の担当への引き継ぎ事項
