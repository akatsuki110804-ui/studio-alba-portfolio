# R03 投稿収集

- 工程: リサーチ
- 上流: R28 進行管理
- 下流: R02 競合調査、R04 トレンド調査、R16 素材収集
- ユーザー承認: 不要（公開動画のURLと表示情報の記録のみで、素材の再利用はしないため（再利用はR16で承認。API利用は設定時に承認））
- 既存の実装: 未実装
- 状態: 下書き（ユーザー回答待ち）

## 目的
調査に使う参考動画（長尺・Shorts）を決められた条件で集め、一つの表（posts.csv）に記録して、他の担当が同じデータを参照できるようにする。

## 責任範囲
### やること
- 収集条件（キーワード・チャンネル・期間・長尺/Shorts）に沿った動画URLの記録
- 画面に表示されている情報（公開日、尺、視聴回数、タイトル、説明文冒頭）の転記
- 重複除去と行IDの付与

### やらないこと
- 動画の良し悪しの評価や傾向分析（→R02・R04）
- 動画・サムネイルのダウンロードや保存（著作権・規約上の理由。素材利用はR16で別途承認）
- YouTubeの利用規約に反する自動取得（スクレイピング等）。YouTube Data APIを使う場合はユーザーの設定・承認が必要
- 非表示の数値の推測

## 入力情報
- videos/<YYYYMMDD>_<slug>/00_brief.md の収集条件
- rules/account.md
- 競合リスト（R02と共通、【未確定：ユーザー回答待ち】）

## 作業手順
1. ブリーフから収集条件を確認する（不足していればR28へ）
2. 手動、または承認済みの方法（API利用は【未確定：ユーザー回答待ち】）で動画を探す
3. 1動画1行で posts.csv に記録する（表示されない項目は空欄ではなく「非表示」）
4. URL重複を除き、行ID（P001〜）を振る
5. 収集条件・方法・件数を collection_log.md に書く

## 出力形式
ファイル: videos/<YYYYMMDD>_<slug>/01_research/posts.csv（列）

| 列名 | 内容 |
|---|---|
| id | P001 形式 |
| url | 動画URL |
| channel | チャンネル名 |
| format | 長尺 / Shorts |
| published_at | 表示されている公開日（不明なら「不明」） |
| duration_sec | 尺（確認できた場合のみ） |
| views_shown | 画面に表示された視聴回数（表示なしは「非表示」） |
| title | タイトル（引用） |
| description_head | 説明文冒頭（引用は最小限） |
| collected_by_query | どの条件で見つけたか |
| collected_at | 記録日 |

ファイル: videos/<YYYYMMDD>_<slug>/01_research/collection_log.md（条件・方法・件数・除外理由）
