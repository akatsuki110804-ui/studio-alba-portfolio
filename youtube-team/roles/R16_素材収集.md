# R16 素材収集

- 工程: 素材準備
- 上流: R13 台本レビュー、R03 投稿収集
- 下流: R20 動画編集、R17 画像生成、R24 キャプション作成
- ユーザー承認: 必要（他者の著作物・人物の写り込み・有料素材の利用はユーザー承認が必要）
- 既存の実装: what-if-youtube/src/asset_manager.py（assets import: 手動ファイルの取り込み）、what-if-youtube/assets_library/（権利台帳としての列は未実装）
- 状態: 下書き（ユーザー回答待ち）

## 目的
台本に必要な既存素材（ユーザーの画面録画・提供素材・フリー素材・許諾済み素材・BGM・効果音）を集め、権利情報を台帳に記録する。

## 責任範囲
### やること
- ユーザー提供素材（画面録画・実験ログ等）の整理
- 利用規約を確認できる素材の収集
- 素材台帳（権利・出典・利用条件）の作成
- 生成が必要なカットの洗い出し（→R17へ依頼）

### やらないこと
- AIによる生成（→R17）
- 図解・モーショングラフィックの作成（→R18）
- 利用条件を確認できない素材の使用
- 実在の人物の肖像・他者の著作物の無許可使用

## 入力情報
- videos/<YYYYMMDD>_<slug>/03_script/script_approved.md
- videos/<YYYYMMDD>_<slug>/02_plan/structure.md の素材種別
- ユーザー提供素材（【未確定：ユーザー回答待ち】）
- rules/approval.md

## 作業手順
1. シーンごとの必要素材リストを作る
2. ユーザー提供素材で埋まるシーンを割り当てる（画面録画に個人情報・通知が映っていないか確認）
3. フリー・許諾済み素材を探し、利用規約のURLと条件（クレジット要否・商用可否）を記録する
4. 有料素材・他者著作物・人物が写る素材は「承認待ち」にしてR28経由で確認する
5. 埋まらないカットを R17（AI生成）・R18（図解）に振り分け、assets_list.csv に保存する

## 出力形式
ファイル: videos/<YYYYMMDD>_<slug>/05_assets/assets_list.csv（列）

| 列名 | 内容 |
|---|---|
| scene | S1 など |
| file | 05_assets/sourced/ 内のファイル名 |
| type | 画面録画/実写/画像/BGM/効果音 |
| source | ユーザー提供/素材サイト名/購入 |
| license_url | 規約URL（ユーザー提供なら「ユーザー提供」） |
| credit_required | 要/不要/不明 |
| cost | 金額（無料は0、不明は「不明」） |
| approval | 不要/承認待ち/承認済み(日付) |
| note | 人物写り込み・個人情報・商標など |

## 完了条件
- [ ] 全素材に出典と規約URL（またはユーザー提供）がある
- [ ] 「承認待ち」が残っていない
- [ ] クレジットが必要な素材がR24に伝わっている
- [ ] 未割り当てのシーンがR17・R18に依頼済み
