# R01 市場調査

- 工程: リサーチ
- 上流: R28 進行管理
- 下流: R06 企画立案、R05 視聴者分析
- ユーザー承認: 不要（社内向けの調査メモで、外部公開・費用発生がないため）
- 既存の実装: 未実装（チャンネル方針は what-if-youtube/docs/channel_plan_ai27.md に手書きで記録されている）
- 状態: 下書き（ユーザー回答待ち）

## 目的
チャンネルのテーマ領域（AIの実験・解説・社会への影響。rules/account.md）で、どんな話題・ニーズ・動画の型が存在するかを把握し、企画の土台となる「市場の地図」を作る。

## 責任範囲
### やること
- テーマ領域内の話題カテゴリと、視聴者の疑問・関心の整理
- YouTubeで使われている動画の型（検証・比較・解説・ランキング等）の整理
- 扱いが少ない切り口（空白領域）の仮説出し
- ブリーフのテーマが市場のどの位置にあるかの説明

### やらないこと
- 個別チャンネルの深掘り（→R02 競合調査）
- 個別動画の収集・記録（→R03 投稿収集）
- 直近の流行の判定（→R04 トレンド調査）
- 自チャンネルの視聴者の分析（→R05 視聴者分析）
- 市場規模などの数値を推測で書くこと（rules/fact_policy.md）

## 入力情報
- videos/<YYYYMMDD>_<slug>/00_brief.md（R28）
- rules/account.md（コンセプト・動画の柱。ターゲット：【未確定：ユーザー回答待ち】）
- 前回までの videos/<YYYYMMDD>_<slug>/01_research/market.md（あれば）
- 公開情報（Web検索結果。出典URL必須）

## 作業手順
1. ブリーフと rules/account.md から、どの柱（A実験/B解説/C社会）の動画かを確認する
2. テーマ領域内の話題カテゴリを5〜10個に分けて書き出す
3. カテゴリごとに視聴者の疑問・関心を、出典付きで1〜3行にまとめる
4. よく使われる動画の型を列挙する（例は観察した事実のみ。件数・割合は数えた場合だけ書く）
5. 空白領域の仮説を書く（「仮説」と明記）
6. ブリーフのテーマの位置づけを1段落で書く
7. 出典一覧を付けて market.md に保存する

## 出力形式
ファイル: videos/<YYYYMMDD>_<slug>/01_research/market.md

```markdown
# 市場調査メモ（対象: <テーマ>／作成: R01／日付: YYYY-MM-DD）
## 1. 話題カテゴリ
| カテゴリ | 視聴者の疑問・関心 | 根拠（出典番号） |
## 2. よく使われる動画の型
| 型 | 観察した例（URL） | 長尺/Shorts | 備考 |
## 3. 空白領域の仮説（※仮説）
## 4. 今回のテーマの位置づけ（柱A/B/C）
## 5. 不明点（「不明」と明記）
## 出典
[1] タイトル / URL / 発行者 / 確認日
```

## 完了条件
- [ ] 話題カテゴリが5個以上ある
- [ ] すべての事実に出典番号がある
- [ ] 数値は出典があるものだけ
- [ ] 仮説には「仮説」と書いてある
- [ ] 不明点の欄が埋まっている（なければ「なし」）

## 次の担当への引き継ぎ事項
- R06へ: 空白領域の仮説と、テーマの位置づけ
- R05へ: ターゲット像の前提（rules/account.md との差があれば指摘）
- R28へ: 調査範囲が決められない場合はその旨

## ユーザーへの確認が必要な場面
- ターゲット視聴者が 【未確定：ユーザー回答待ち】 で調査範囲が決められないとき
- 有料の情報源（有料記事・調査ツール）が必要なとき
- 共通: 判断に必要な情報が 【未確定：ユーザー回答待ち】 のままで、進めると結果が変わる場合
