# Special Day Bingo（写真ビンゴ Webアプリ）

ビンゴカードの各マスが個別リンク（`#/m/1`〜`#/m/25`）になっていて、
マスを開いて写真を撮る／選ぶと、そのマスが「達成」になるWebアプリです。

ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）です。

## できること
- 5×5 のビンゴカード（中央は FREE）
- マスをタップ → ミッション詳細ページ → 写真を撮影／選択して登録
- 写真を入れたマスはカード上に写真のサムネイル＋「OK」スタンプ
- 縦・横・斜めがそろうと BINGO 判定（そろった列は金色の枠＋紙吹雪）
- 写真ごとに「ひとことメモ」
- アルバム画面（登録した写真を一覧）
- 遊び方画面、リセット

## データの保存先
写真とメモは **その端末のブラウザ内（IndexedDB）** に保存されます。
サーバーには送信されません。写真は保存時に長辺1600pxへ縮小されます。
別の端末・別のブラウザとは共有されません。

## マスの内容を変える
`missions.js` の `missions` を編集します（左上から右へ順に25個）。

## ローカルで確認
```bash
cd photo-bingo
python3 -m http.server 8000
# → http://localhost:8000
```

## 公開（Vercel の例）
Vercel で新しいプロジェクトを作成し、Root Directory を `photo-bingo`、
Framework Preset を「Other」にしてデプロイするだけで公開できます。
（GitHub Pages / Netlify など、静的ファイルを置ける場所ならどこでも動きます）
